# Support

ShareLint is maintained on a best-effort basis.

## Getting help

1. Read the README and relevant documentation.
2. Search existing issues for the same symptom or question.
3. Use the question/setup-help form for installation or documented behavior.
4. If the problem appears to be a bug, open a bug report with a minimal
   synthetic reproduction.
5. Use a feature request for new formats, scanners, policies, or integrations.

Include the ShareLint version, operating system, installation method, command,
expected behavior, and actual behavior. Remove or replace usernames, local
paths, matched values, and document contents before posting.

## Support boundaries

The project can help with reproducible installation failures, documented
behavior, and defects in supported features. It does not provide:

- review of real confidential files or scanner output;
- legal, regulatory, privacy, or compliance advice;
- a guarantee that an artifact is anonymous or safe to share;
- private consulting or guaranteed response times;
- support for unmaintained versions or undocumented modifications.

Possible vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md). Never attach a real sensitive artifact to a public
issue.
