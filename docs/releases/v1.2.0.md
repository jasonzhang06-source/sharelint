# ShareLint 1.2.0 — verify the handoff, offline

## Added

- `sharelint verify` checks a pack receipt, exact native report bytes, and the
  delivered ZIP without uploading or extracting files.
- Independent report-summary recomputation, recorded-policy binding checks,
  bounded ZIP content-manifest verification, and optional receipt digest pinning.
- A reusable bounded JSON report validator and public `verify_receipt` Python API.
- Explicit blocked/mismatch/error outcomes and privacy-safe aggregate output.
- Native wheel and standalone smoke tests now verify a freshly packed bundle.

## Fixed

- Nonblocking source opens on supported platforms prevent a file-to-FIFO race
  from hanging scan, pack, or publication checks. Pack readers also recheck
  final path identity and exact byte count.

## Try it

```sh
pipx upgrade sharelint
sharelint pack ./approved-files -o delivery.zip --receipt receipt.json --report report.json
sharelint verify delivery.zip --receipt receipt.json --report report.json
```

Integrity verification is not a signature, producer authentication, a new
privacy scan, or a safety guarantee. Keep contextual receipts and reports
private. Receipt fields never choose which local files the verifier opens.

Existing commands, defaults, Python 3.11+ support, and report/receipt schemas
remain compatible. The core remains local-only and dependency-free.

See [verification details](https://github.com/jasonzhang06-source/sharelint/blob/v1.2.0/docs/verification.md).
