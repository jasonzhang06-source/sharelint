# ShareLint 2.0.0 — reviewable, bound handoffs

- Create and inspect private handoff plans before export.
- Require unchanged source, effective policy, producer version, and scan
  snapshot when packing with a plan; all fresh strict checks still run.
- Bind exact plan bytes to receipts and verify the whole handoff offline.
- Minimize every new receipt: ZIP entry indices replace repeated filenames.
- Retain offline verification of legacy v1 receipts, with explicit v2 schemas
  and migration guidance.

Upgrade: `pipx upgrade sharelint` or `uv tool upgrade sharelint`.

Start with `sharelint plan create ./handoff -o handoff.plan.json`, then
`sharelint pack ./handoff -o delivery.zip --plan handoff.plan.json`.

**Migration:** new receipts use schema 2.0.0 and `files[].entry`, not
`files[].path`. Update machine consumers or use `sharelint verify`. Native scan
reports retain schema 1.0.0. See [migration](https://github.com/jasonzhang06-source/sharelint/blob/v2.0.0/docs/migration-2.md)
and [handoff plans](https://github.com/jasonzhang06-source/sharelint/blob/v2.0.0/docs/handoff-plans.md).

All inspection stays local. Plans and receipts are not signatures, approvals,
or guarantees of privacy. Originals are not cleaned or modified; no OCR or
pixel-content inspection is added. Reports and plans remain sensitive.
