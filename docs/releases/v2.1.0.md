# ShareLint 2.1.0 — bounded batch preflight

- Check multiple explicit files/directories with one command or a reusable
  private TOML manifest.
- Keep per-target findings/coverage counts and errors, with deterministic
  input-order IDs and no filenames or evidence in aggregate output.
- Enforce a shared inspection-byte budget across top-level and nested content;
  unattempted targets remain explicit and cannot produce a passing batch.
- Export script-free local HTML or a distinct versioned batch JSON report.
- Preserve existing single-target scan, plan, pack, and receipt contracts.

Try `sharelint batch ./handoff-a ./handoff-b --format html -o batch.html`.

Upgrade with `pipx upgrade sharelint` or `uv tool upgrade sharelint`.
See the [batch guide](https://github.com/jasonzhang06-source/sharelint/blob/v2.1.0/docs/batch.md)
for manifests, finite limits, and exit codes.

Every target needs complete coverage. All work remains local; originals are
unchanged. Aggregate results are not signatures, receipts, or safety guarantees.
No OCR, pixel inspection, or automatic sanitization is added.
