# ShareLint 1.3.0 — review what changed

Historical development record. This intermediate tag and release are not being
restored. Its changes are included in [2.0.0](v2.0.0.md); use the current
[installation guide](../troubleshooting.md), not this checkpoint, to install.

## Added

- `sharelint diff before.json after.json` compares validated rule/severity
  counts without reusing ephemeral evidence fingerprints as stable identities.
- Explicit review reasons for increased blockers, incomplete coverage,
  reduced inspection, unknown rules, and changed producer/policy settings.
- Console, JSON, and self-contained, script-free HTML comparison outputs.
- A separate comparison JSON Schema and public `compare_reports` Python API.
- Privacy regressions: imported filenames, previews, notes, and unknown rule
  identifiers never appear verbatim in comparison output.
- Installed wheel and native portable smoke tests now exercise report comparison.

```sh
sharelint diff before.json after.json --format html -o comparison.html
```

This is an aggregate review aid, not a claim that particular secrets were
removed. Unchanged counts can hide different findings. Existing blockers still
require attention, and `pack` retains its independent complete-coverage gate.
All earlier commands, native scan/receipt formats, and defaults remain compatible.

See [comparison details](../comparison.md).
