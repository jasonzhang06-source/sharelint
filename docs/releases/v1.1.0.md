# ShareLint 1.1.0 — repeatable local policies

Define a sharing policy once and apply it consistently to scans and bundles.

- Built-in `default`, `public`, and `strict` profiles.
- Explicit TOML configuration, custom named profiles, and all scan resource limits.
- `config init` writes a new commented template; `config show` explains the full effective policy.
- `scan` and `pack` share resolved thresholds and limits. Packing never accepts incomplete coverage.
- Bounded, no-follow configuration reads reject malformed, unknown, or changed inputs without printing their contents.

```sh
pipx upgrade sharelint
sharelint config init -o sharelint.toml
sharelint scan ./handoff --config sharelint.toml --profile client
```

[Configuration guide](https://github.com/jasonzhang06-source/sharelint/blob/v1.1.0/docs/configuration.md)

No automatic config discovery, telemetry, uploads, OCR, or original-file changes.
Existing defaults, machine schemas, and commands remain compatible with 1.0.
Standalone archives cover Linux glibc x86-64, Windows x86-64, and both Mac
architectures, with checksums and build provenance. Windows remains unsigned;
macOS remains ad-hoc signed without notarization.
