# ShareLint 3.0.0 — reviewable text derivatives

- Plan deterministic UTF-8 text redactions without storing source text or filenames.
- Inspect bounded edit positions and rules before explicitly applying them.
- Preserve originals, recheck source identity, and publish only a new, reopened,
  rescanned derivative with no remaining known findings and complete coverage.
- Bind a distinct transformation receipt to exact plan, output, and native-report
  bytes; verify the complete record offline.
- Retain existing scan, batch, handoff-plan, pack, and v2 receipt contracts.

```bash
sharelint redact plan private.log --name public.log -o redaction.plan.json
sharelint redact inspect redaction.plan.json
sharelint redact apply private.log --plan redaction.plan.json -o public.log
```

Upgrade: `pipx upgrade sharelint` or `uv tool upgrade sharelint`.

Read the [text-derivative guide](https://github.com/jasonzhang06-source/sharelint/blob/v3.0.0/docs/redaction.md)
and [compatibility review](https://github.com/jasonzhang06-source/sharelint/blob/v3.0.0/docs/migration-3.md).

Limits: UTF-8 text only, at most 4 MiB and 10,000 candidate edits, with lower
operator limits respected. Private-key blocks, PDFs, Office/ZIP containers,
images, OCR, and binary input are not automatically cleaned. All work remains
local. Plans, findings, and receipts are not approval, authentication, or a safety
guarantee. Review derivatives before sharing.
